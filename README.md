# Métrica · Tablero de Control Automotor · Grupo Lorenzo

Demo de producto de **Métrica**: tablero de control para Grupo Lorenzo (Mendoza) con escucha social, reputación en Google, presencia local en Maps, SEO/GEO (visibilidad en IA) y mercado automotor, comparado con la competencia.

> **Todos los datos del tablero son simulados** con fines ilustrativos.

- `index.html`: el tablero (GitHub Pages)
- `propuesta_lorenzo.pdf`: documento explicativo (generado desde `propuesta_lorenzo.html`)
- `shots/`: capturas del tablero usadas en el PDF
